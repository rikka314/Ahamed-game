> 状态：`DRAFT`  
> 用途：交给美术手绘，之后由开发负责切片、地图组装、碰撞和稳定 ID 绑定。  
> 范围：只包含任务卡 1 的诊所地图、建筑、家具和静态道具；角色、医疗动画和升级外观不在本清单内。

## 先定一个最省事的画法

建议先只画 **32×32 px 原生版**：

- 地图网格：26×16，世界尺寸 832×512 px。
- 每个基础格：32×32 px，不要开抗锯齿，不要画模糊阴影。
- 原文件：`clinic-community-master-32.aseprite`。
- 导出文件：`clinic-community-master-32.png`，sRGB、透明背景。
- 使用一张连续图集，推荐先建 512×512 px（16×16 个格子），留一部分空位给变体。
- 多格家具按实际大小画，不需要强行塞进一个 32 px 格子。
- 保留第 1 格为完全透明的空 tile。
- 暂用 0 margin / 0 spacing / 0 extrusion；如果实机出现接缝，再作为 H3 问题处理。

32 px 版集成后，先看游戏内截图和 Android 横屏。16 px 版如果仍需要，必须重新按 16×16 网格手画，不能把 32 px 版简单缩小冒充原生版。

## 像素风格硬性要求

- 方向：“暖晨社区诊所”，关键词为暖、专业、清晰、克制、有人情味。
- 视角：顶视/伪顶视的正交像素地图，不做等距斜视。
- 边缘：使用像素硬边，关闭抗锯齿、模糊、光晕和大面积渐变。
- 阴影：只画贴地接触和前后遮挡需要的阴影。
- 清晰度：地面和墙面低对比，可交互物件可比环境稍亮/稍暖。
- 文字：不把中文、英文、叫号数字或医疗数值烘进 PNG。
- 品牌：不放 Logo、水印、真实设备品牌或可识别的商标造型。
- 临床安全：电脑、血压设备、告示板和纸张上不画诊断答案。
