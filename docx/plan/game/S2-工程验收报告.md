## 交付结果

- 真实 Tiled `.tmj` 灰盒取代硬编码场景作为首选输入，并保留程序 fallback。
- 地图实现 `Ground / Decoration / Collision / AbovePlayer / Objects` 五层合同、稳定对象 ID、发布脚本和 placeholder manifest。
- 启动链为 `BootScene → PreloadScene → WorldScene`；加载失败提供 warning/fallback，不会停在无限黑屏。
- 纯 TypeScript clinic-flow 实现确定性的开场、电脑、开诊、两人队列、叫号、进门、独占座位、离场和下一位循环，并按 command ID 幂等。
- 两名患者各有站立/坐姿 placeholder；到座后切换坐姿、离场前恢复站姿，并通过可观察的 visual state 验证。
- React/Phaser bridge 只交换可序列化事件；DOM 负责气泡、电脑、操作和旋转门。
- coarse-pointer 竖屏暂停世界，横屏恢复；电脑模态面板打开时隔离 Phaser 输入。
- 移动端使用独立安全镜头锚点；横屏 stage 内叠放动作与方向键，两个候诊患者、门、接诊区、Canvas 与触控键可同屏观察。
- 桌面键盘、移动触控、桌面/移动构图、双患者完整循环已纳入 Playwright。
- 商店/升级明确 disabled 并标注 S7，不提前伪装完成。

## 人工测试入口

访问 `http://localhost:3020`：

1. 等待黑屏淡入与医生开场气泡；
2. 打开电脑，检查开始接诊/商店/升级入口；
3. 开始接诊，依次叫入并用灰盒按钮送走两名患者；
4. 用 WASD/方向键或移动触控绕行；电脑面板打开时确认世界不移动；
5. coarse-pointer 模拟/真机切到竖屏，确认暂停提示，再恢复横屏；
6. 桌面检查上/下锁定区，移动端检查左队列—门—接诊区安全构图。
